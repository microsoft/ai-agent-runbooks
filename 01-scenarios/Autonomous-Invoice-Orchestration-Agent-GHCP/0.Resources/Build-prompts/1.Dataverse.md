# Build Prompt — Dataverse Table

Use **Get started with Copilot** in the **Tables** area of [make.powerapps.com](https://make.powerapps.com/) to create the **Auto Invoice Review** Dataverse table in the **Autonomous Invoice Orchestration** solution. AI builds the table, but it can skip or change columns. This page therefore covers how to remove the sample rows that Copilot adds, what to check afterwards, how to add or change a column by hand. The same solution is later used for the agent and the workflow.

If you prefer to build the table by hand, create the solution first, with your organization's publisher, and set it as your preferred solution (see Step 1-1 of the [Runbook](../../3.Runbook.md#step-1-1-create-the-dataverse-solution-and-table)) and add the table and columns from the [data model](../Capability-matrix.md#dataverse-data-model).


## Create the table with Copilot

### Run the prompt

1. In solution select **+ New > Table > Tables**

   ![](images/create-table.png)

2.  Select **Start with Copilot** 

      ![](images/create-table-2.png)

3. In the **Table options** menu of the prompt box, set the number of tables to **One table** and paste the prompt below and click **Generate**
   
   ![alt text](images/generate-table.png)

   ```text
   Create "Auto Invoice Review" table with these 18 columns. Make sure that table really contains all these columns

   | Display Name | Data Type | Options |
   | --- | --- | --- |
   | Accounting GL Code | Text | 100 |
   | Billed to Legal Entity | Boolean | — |
   | Currency | Text | 100 |
   | Decision | Choice | NEEDS_REVIEW, READY_FOR_APPROVAL |
   | Due Date | Date Only | — |
   | Invoice Date | Date Only | — |
   | Invoice Key | Text | 850 |
   | Invoice Number | Text | 100 |
   | Issues Found | Multiline Text | — |
   | Purchase Order Number | Text | 100 |
   | Review Link | URL | 200 |
   | Source Link | URL | 200 |
   | Subtotal | Decimal | — |
   | Summary | Multiline Text | 2000 |
   | Tax | Decimal | — |
   | Total Amount Due | Decimal | — |
   | Vendor ID | Text | 100 |
   | Vendor Name | Text | 100 |
   ```

   The prompt asks for 18 columns. It does not list a GUID column, because Dataverse creates the row ID itself as the table's native primary key. The scenario calls that value the **Auto Invoice Review ID**, and it is checked separately in [Check the table](#check-the-table).

4. Copilot opens the **Create new tables** workspace.
   
5. In the workspace, select **Auto Invoice Review** table and expand it to show all columns. Compare the list with the red box in the screenshot below: one table, 18 columns, and no separate **Name** column. If there is more than one table, select **...** on the extra card and then **Remove**.
   
   ![Copilot Create new tables workspace showing the Auto Invoice card with 18 columns, and the card menu open with View data highlighted](images/copilot-table-card-view-data.png)

   | Display Name | Expected data type | Expected setting |
   |---|---|---|
   | Accounting GL Code | Text | Maximum length 100 |
   | Billed to Legal Entity | Yes/No | Two options |
   | Currency | Text | Maximum length 100 |
   | Decision | Choice | Exactly two options, `NEEDS_REVIEW` and `READY_FOR_APPROVAL`, written with underscores. No default value |
   | Due Date | Date | Behavior **Date Only**, not Date and Time |
   | Invoice Date | Date | Behavior **Date Only**, not Date and Time |
   | Invoice Key | Text | Maximum length 850 |
   | Invoice Number | Text | Maximum length 100 |
   | Issues Found | Multiline text | Maximum length at least 4000. Raise it if it is smaller, because a list of issues can be long |
   | Purchase Order Number | Text | Maximum length 100 |
   | Review Link | URL | Maximum length 200 |
   | Source Link | URL | Maximum length 200 |
   | Subtotal | Decimal number | Precision 2. Not Currency or Floating point |
   | Summary | Multiline text | Maximum length 2000 |
   | Tax | Decimal number | Precision 2. Not Currency or Floating point |
   | Total Amount Due | Decimal number | Precision 2. Not Currency or Floating point |
   | Vendor ID | Text | Maximum length 100 |
   | Vendor Name | Text | Maximum length 100 |

   <br>
    1. If a column is missing or wrong, do not send Copilot another prompt, because it can rename or drop other columns. You can add and edit columns before saving. NOTE! You can change column max characters limit here that need to be done after table is saved
   
   ![alt text](images/modify-columns.png)

   

### Delete the sample rows

Copilot adds sample rows to the table. Delete all of them before the agent runs. Otherwise they pollute duplicate detection, reports and the first test, which expects an empty table.

1. On the **Auto Invoice** card, select **...** and then **View data**. The first screenshot above shows this menu.
2. The grid lists the sample rows. In the screenshot below, they are five rows with GL codes **GL100** to **GL500**. Write down every column header that shows a red `*`, which means business required. [Check 2](#check-2-no-column-is-required) clears them.
3. Select the circle in the header row to select all rows, then select **Delete rows** and confirm.

   ![Auto Invoice data grid with five sample rows selected and the Delete rows button highlighted. Accounting GL Code and Currency show a red asterisk](images/view-data-delete-rows.png)

4. Reopen **View data**. Only the empty line with **Enter text** may remain. Do not type into it.


### Save the table and confirm the solution

1. Select **Save and exit**.
   
   ![Save table](images/save-table.png)
   
2. Open table and select **Columns**. Update **Maximum character count** of columns like Review Link, Source Link and Summary. See the table above of value for all the columns 
   
   ![alt text](images/table-columns-update.png)
