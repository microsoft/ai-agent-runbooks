# Resources — Client Meeting Preparation Agent

Place scenario assets here:

| Folder / file | Purpose |
|---|---|
| `Compliance/` | The signed boundary statement and the compliance review of real briefings |
| `Barriers/` | Information barrier map and the permission test matrix, including the segment-change evidence |
| `Instructions/` | Version-controlled agent instructions — boundaries block first |
| `Evaluation/` | The 25-client evaluation set and five-axis scoring results |
| `Prompts/` | The blocked-prompt / working-rewording list, used as user enablement material |
| `Baseline/` | Preparation-time and file-note-timeliness baseline from Phase 0 |
| `Images/` | Screenshots referenced from `3.Runbook.md` |

> 📌 The signed boundary statement and the barrier test evidence are the two artifacts that
> determine whether this agent goes live. Keep them current — both need re-signing after any
> material change to instructions, data sources, or platform behaviour.
