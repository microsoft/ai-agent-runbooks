# Resources — Contract & Legal Intelligence Agent

| Folder / file | Purpose |
|---|---|
| `Boundary/` | Signed legal boundary statement — the gating artefact |
| `Standard-Positions/` | Versioned clause library, fallbacks, red lines, risk taxonomy |
| `Instructions/` | Version-controlled agent instructions |
| `Evaluation/` | Lawyer-baseline results, boundary test evidence, consistency runs |
| `Redlines/` | Sample tracked-changes outputs used in review |
| `Baseline/` | Pre-agent review times and throughput |

> 📌 The standard positions are versioned deliberately. Every analysis must record which version it
> compared against, or the result is not reproducible.
