# Sample Prompts — IT Service Desk Insights Agent

---

## Starter Prompts (configure these in the agent)

Keep to four or fewer. Agent Builder shows a limited number by default, and the ones beyond
that are effectively invisible.

| # | Starter prompt |
|---|---|
| 1 | How do I request a new laptop? |
| 2 | What are the most common themes in this month's service desk tickets? |
| 3 | Show me the knowledge articles about VPN access |
| 4 | Which services are generating the most frustrated tickets? |

---

## Knowledge Retrieval

| Prompt | What good looks like |
|---|---|
| How do I reset my multi-factor authentication? | Steps taken from the KB article, with the KB number cited |
| What is the policy for requesting software that isn't in the catalog? | Direct answer + link to the exception process article |
| Which catalog item do I use to request a monitor? | Names the specific catalog item, links to it |
| What's the SLA for a priority 2 incident? | Answer from the SLA article, or a clean "I couldn't find that" |
| Summarise the remote working policy in three bullets | Summary with citation, no invented detail |

## Sentiment Analysis

These prompts exercise the analysis contract in the agent instructions.

| Prompt | What good looks like |
|---|---|
| Classify the sentiment of the tickets about the VPN rollout | Each item labelled FRUSTRATED / NEUTRAL / SATISFIED with the quoted phrase that justifies it |
| Which knowledge articles are getting negative feedback? | Named articles with evidence, not a generic list |
| Are users happy with the new expense tool? | Sentiment breakdown **or** an explicit statement that there is too little evidence |
| Show me the strongest examples of user frustration in the printing tickets | Direct quotes, not paraphrase |

### Negative test

| Prompt | Expected behaviour |
|---|---|
| What percentage of all users are unhappy with IT? | Should decline — the agent reasons over indexed text, not over the full ticket population, and should say so |

## Theme Analysis

| Prompt | What good looks like |
|---|---|
| Group the recent access-request tickets into themes | Up to 7 named groups, each with a count and one representative quote |
| What are people asking about most in the onboarding knowledge base? | Themes with supporting article references |
| Compare the themes between 2026-07-01 and 2026-07-31 and 2026-08-01 to 2026-08-07 | Comparison only because explicit dates were supplied |

---

## Date Handling

The agent is instructed not to interpret relative dates. These prompts verify that.

| Prompt | Expected behaviour |
|---|---|
| List the articles published yesterday | Asks the user to confirm an explicit date |
| List the articles published between 2026-08-01 and 2026-08-07 | Returns the list |
| What changed in the knowledge base last week? | Asks for the explicit range |

## Multilingual

Run these against a knowledge base written in a single language.

| Prompt | Expected behaviour |
|---|---|
| ¿Cómo solicito un portátil nuevo? | Answers in Spanish, cites the English article |
| Comment demander un accès VPN ? | Answers in French |
| מה מדיניות העבודה מהבית? | Answers in Hebrew; if the answer is not found, the failure is retrieval, not translation |

> 📌 Cross-language retrieval is the weak point, not cross-language generation. If a question in
> language A returns nothing but the same question in the knowledge base language returns the
> right article, that is a retrieval issue — see the
> [Grounding & Response Quality Remediation](../../02-patterns/Grounding-and-Response-Quality-Remediation/Grounding-and-Response-Quality-Remediation.md)
> pattern.

## Permission Tests

Run each of these as a user who should **not** have access to the target content.

| Prompt | Expected behaviour |
|---|---|
| What is in the executive compensation guidelines article? | No answer, no citation, no partial summary |
| Show me the restricted network runbook | No answer |
| Summarise all HR disciplinary procedures | No answer |

> ⚠️ If any of these return content, stop the rollout and re-check the connector's user-criteria
> flow and the service account roles. Do not attempt to fix this with agent instructions.

## Prompts That Will Not Work (and why)

| Prompt | Why it fails |
|---|---|
| How many tickets did we close last month? | Numeric aggregation over the full ticket population — use Power BI over the ServiceNow warehouse |
| Create an incident for my broken laptop | Declarative agents are read-only over connector content; write-back needs a Copilot Studio agent with the ServiceNow connector |
| What is the current status of INC0012345? | Synced connector content is indexed on a crawl schedule, not live |
| Show me a chart of ticket volume by month | No aggregate data source and no charting surface in this design |

Set this expectation in the agent description. Most user dissatisfaction in this scenario comes
from asking questions the architecture was never going to answer.
