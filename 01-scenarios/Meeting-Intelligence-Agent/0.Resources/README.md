# Resources — Meeting Intelligence & Action Tracking Agent

| Folder / file | Purpose |
|---|---|
| `Consent/` | Signed legal position, works council agreement, excluded meeting categories |
| `Instructions/` | Version-controlled instructions — evidence rule and ownership rules |
| `Evaluation/` | 15-transcript test set results, invented-action gate evidence |
| `Baseline/` | Chair-produced action lists used for recall comparison |
| `Tracking/` | Action closure rate and ageing reports |

> 📌 The invented-action test evidence is the artefact that gets this scenario approved. Keep it
> current — re-run it after every model or instruction change.
