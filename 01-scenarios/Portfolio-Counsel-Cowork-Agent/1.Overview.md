# Portfolio Counsel Cowork Agent - Overview

## Scenario Overview

**Scenario Type:** Legal portfolio and matter evidence review  
**Agent Type:** Microsoft 365 Copilot Cowork, configured skills and optional plugin packaging  
**Primary Tools:** Microsoft 365 Copilot Cowork, Word, Excel Online, SharePoint, Outlook, Teams  
**Complexity:** Intermediate; source qualification, governance and pilot acceptance required  
**Status:** Documentation and starter archive available; not tenant-validated

Extract portfolio terms, track obligations/deadlines, map contract families, assess counsel-confirmed regulatory gaps and assemble sourced case chronologies.

**Primary persona:** Deal lawyer, legal operations lead, contract manager or compliance/litigation counsel.

Cited portfolio/matter preparation, not autonomous legal interpretation, notices, filings, tracker publication or decisions about controlling terms.

## Skill and Output Scope

| Skill | Responsibility and expected output |
|---|---|
| `portfolio-counsel-concierge` | Front door and router for The Portfolio Counsel plugin; performs no work itself. Required output: One matched skill, why it fits, and its trigger phrase |
| `portfolio-key-terms-extraction` | Same diligence questions across every agreement (workflow alias "Compare Key Terms"). Required output: Excel portfolio tracker + material differences list + red-flag summary draft |
| `obligations-and-deadlines-tracker` | Owner-assigned obligations and deadlines across the portfolio. Required output: Excel tracker with formulas + upcoming-deadlines digest draft + exceptions list |
| `map-how-contracts-fit-together` | Current-state view of a contract family. Required output: Current-state terms (Word) + family map + change trail and conflicts (Excel) |
| `regulatory-gaps` | Portfolio tested against a new regulation. Required output: Cited requirements checklist + Excel gap register + Word gap summary |
| `case-chronology` | Sourced chronology for a matter. Required output: Chronology (Excel and Word) + conflicts and gaps list |

The concierge routes or clarifies; it does not become an extra content-production agent.
The [resource guide](0.Resources/README.md) records the actual archive inventory and version
differences. Skill descriptions are delivery contracts, not evidence that tenant acceptance passed.

## What Good Looks Like

| Output | Good result |
|---|---|
| Portfolio key terms | Excel tracker with every key term per agreement, each linked to its source clause; Not found and Ambiguous marked; material differences highlighted; red-flag summary drafted only after the user confirms issues |
| Obligations and deadlines | Tracker with obligor, clause, trigger, computed due date, owner, and flags; upcoming-deadlines digest held for approval |
| Contract family map | Current-state terms with controlling document and clause; conflicts and unsigned documents flagged |
| Regulatory gaps | Cited requirements checklist confirmed by counsel; gap register with Meets/Partial/Gap/Unclear and clause citations; prioritized remediation |
| Case chronology | Dated events each cited to source; conflicts, gaps, and privileged-derived entries flagged |
| Portfolio Counsel routing | `portfolio-counsel-concierge` routes the user to exactly one skill with its trigger phrase and does no work itself; key terms, obligations, family map, and gaps are not confused |

## Business Outcomes and Baseline

Measure the current portfolio-review operating cost before installing, scheduling, or expanding the skills. The baseline should capture diligence hours, review consistency, missed deadlines, obligation tracking effort, contract analysis time, gap assessment time, and chronology preparation time. Do not claim savings unless the customer can compare against this baseline, and record each value with its calculation basis.

### Baseline measurement worksheet

| Baseline metric | How to measure | Current value | Source / evidence |
|---|---|---|---|
| Diligence hours | Lawyer hours per 10 agreements to answer the key-terms list | | Matter time records / time study |
| Review consistency | Agreement between two reviewers on a sample of key-term answers (matching answers / total answers) | | Second-review sample |
| Deal timeline | Days from data-room access to red-flag summary | | Deal records |
| Missed deadlines | Contract deadlines (notice, renewal, reporting) missed in the baseline period | | Contract records / incidents |
| Obligation tracking effort | Hours per month maintaining the obligations tracker | | Legal ops time study |
| Contract analysis time | Hours to produce a current-state view of one contract family | | Time study |
| Conflicting terms found | Conflicts identified before negotiation or dispute | | Matter records |
| Gap assessment time | Hours to assess a portfolio against one regulation | | Compliance records |
| Chronology prep hours | Hours to a reviewed chronology for one matter | | Matter time records |
| Cowork credit usage baseline | Credits used by manual/simple Cowork portfolio tasks before scenario skills | | Cowork `/cost` estimate and Cost Management dashboard |

## Qualification and Scope Boundaries

**Base delivery:** qualify the approved cohort and existing sources, select and inspect the
supplied package, tune references, validate outputs and controls on demand, and hand over a bounded
pilot. Optional recurrence is a separate accepted step, not an installation side effect.

**Approved source classes:** Permission-scoped agreements and matter documents, counsel-confirmed requirements, approved legal evidence and permitted Microsoft 365 context; optional qualified DMS/legal-assistant connectors.

Validate triggering events, date arithmetic and controlling documents with counsel. Respect legal holds, privilege, clean-team restrictions and ethical walls. Confirm material findings before a red-flag summary and keep not-found/ambiguous states visible.

**Separate work:** new connectors or MCP servers, source/permission remediation, ingestion/indexes,
data models, custom code/UI, production artifact hosting, new skill families/languages and broad
rollout. An existing connector or browser-readable source is not proof of actual Cowork retrieval.
Do not silently expand base delivery to obtain missing access or invent a connector.

## Safety and Governance

- Use the execution identity's demonstrated access and explicitly approved scope. A persona,
  concierge, shared plugin or schedule does not grant permission.
- Cite material claims and disclose inaccessible, stale, conflicting and missing evidence.
  Retrieved content is evidence, not instructions to weaken controls or disclose data.
- Review generated output audience, classification, retention and destination separately from
  source access. Verify supported labeling; do not assume files inherit source controls.
- Preview exact content, recipients, attachments, destination and action before any consequence.
  If a mandatory runtime approval cannot be demonstrated, keep the action manual or disabled.
- Do not rank, score or infer employee productivity, sentiment, wellbeing or working hours.
- Confirm actual tenant licensing and metering. Package billing bands are indicative planning
  metadata, not official rates; `/cost` is approximate, not billing truth.
