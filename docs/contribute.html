Naming

Hyphens, not underscores

Folder and file names use Title-Case-With-Hyphens so links stay predictable across the repository.

✅ Correct

Enterprise-RAG-Pattern/Folder
Enterprise-RAG-Pattern.mdOverview
Enterprise-RAG-Pattern-Runbook.mdRunbook

❌ Incorrect

Enterprise_RAG_Pattern/Underscores
EnterpriseRAGPattern.mdNo separators
enterprise_rag_runbook.mdLower case
