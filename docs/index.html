Overview

Not documentation. Delivery material.

Product documentation tells you what a feature does. These runbooks tell you what to build, in what order, what will go wrong and what to do about it — grounded in Copilot Studio, Microsoft Foundry and Microsoft 365 Copilot deliveries that actually reached production. Every scenario is self-contained and standardised, so any engineer can pick a folder up mid-engagement and deliver it.
